# 포켓몬 플레이

아이들을 위한 한국어 포켓몬 퀴즈. 공식 한국 포켓몬 도감의 전체 기본 포켓몬 1,025종을 사용합니다.

- 첫 방문: 흰 화면의 포켓볼과 “트레이너 이름을 넣어줘.” 안내 아래에서 이름(최대 12자)을 입력한 뒤 게임에 진입합니다. 이름은 이 브라우저에 기억하고, 메인 화면의 이름 버튼으로 변경할 수 있습니다. 랭킹 등록에는 이 이름을 자동으로 채우며 저장 전에 해당 기록의 이름을 별도로 수정할 수 있습니다.
- 타임어택: 쉬움(친숙한 43마리), 보통(전체 1,025종), 어려움(전체 1,025종 실루엣). 모두 60초, 4지선다, 정답 100점. 시간은 왼쪽, 점수는 오른쪽에 표시합니다. 연속 정답 보너스는 10점씩 늘어나며 최대 100점입니다.
- 마스터 도전: 한글 이름을 글자마다 한 칸씩 입력하며, 시간 제한 없이 10문제를 풉니다. 한글 조합과 문제 사이의 입력 흐름은 하나의 실제 입력 요소로 유지합니다. 쉬움은 친숙한 43마리, 보통은 전체 포켓몬, 어려움은 전체 포켓몬 실루엣입니다. 오답을 입력하면 같은 위치의 맞춘 글자는 초록색, 틀린 글자는 빨간색으로 표시하고 “괜찮아! 다시 해보자!”를 보여줍니다. 답을 수정하면 다시 확인할 수 있고 다음문제를 누르면 오답으로 기록하고 넘어갑니다. “패스”를 누를 때만 정답을 글자 칸에 채우고 원래 모습을 보여줍니다. 별도의 정답 안내 문장은 표시하지 않으며 다음문제를 눌러야 칸이 비워지고 새 문제로 넘어갑니다. 정답과 패스도 자동으로 넘어가지 않습니다. 정답당 100점에 난이도 배수 1/2/3을 적용합니다. 이미지 준비 완료 후 20초 동안 줄어드는 0·50·100·150점 눈금 게이지에 따라 최대 50/100/150점 보너스를 더하며, 게이지가 끝나도 시간 제한 없이 기본 점수로 풀 수 있습니다. 힌트는 문제마다 한 번만 쓸 수 있고 쉬움·보통은 첫 글자, 어려움은 임의의 한 글자를 알려줍니다. 힌트를 쓰면 시간 보너스가 즉시 사라지고 정답 점수는 절반(50/100/150점)이 됩니다. 서버는 결과·힌트·문제별 소요 시간으로 같은 점수를 계산하며 이전 클라이언트의 시간 없는 제출은 기본 점수만 적용합니다.
- 랭킹: 정상적으로 게임을 완료하고 0점보다 높은 점수로 모드·난이도별 TOP 20에 진입하면 이름 입력창이 자동으로 열립니다. 게임 완료창에서 해당 모드의 TOP 20을 보여주며 강조된 내 행에 이름(최대 12자)을 직접 입력합니다. 별도의 내 순위·점수 박스는 표시하지 않습니다. Enter 또는 체크 버튼으로 저장하면 같은 화면에서 저장된 이름을 확인할 수 있습니다. 이름을 비우거나 공백만 입력하면 전체 포켓몬 중 랜덤 포켓몬 이름으로 저장합니다. 동점은 최근에 등록한 기록을 먼저 보여줍니다. 날짜는 한국 시간 기준 오늘은 HH:mm, 1~6일은 일전, 이후 주전·개월전·년전으로 표시하며 1~3위는 금·은·동메달, 4위부터는 숫자로 표시합니다. 랭킹 화면은 타임어택·마스터 탭 아래에 쉬움·보통·어려움 버튼을 제공합니다. 각 모드의 최고 20개를 보존하고, 그만하기도 종료 랭킹을 표시하고 획득한 점수로 등록할 수 있습니다. 0점이나 이미지 오류는 등록하지 않습니다. 랭킹 이름 입력 화면에서 다시 도전을 누르면 입력한 이름으로 기록을 저장한 뒤, 선택한 모드·난이도를 유지한 시작 화면으로 돌아갑니다. 저장에 실패하면 이름 입력 화면을 유지하고 다시 저장할 수 있습니다. 이름 입력 레이어는 실제 보이는 화면 너비 안에 맞추며, 키보드가 열리면 여백을 줄이고 입력 중인 행을 보이게 유지합니다. 새로 등록한 기록은 AWS DynamoDB에 저장해 다른 기기와 공유합니다. 기존 개인 기록은 브라우저에 보존하지만 공유 순위로 자동 전송하지 않습니다.
- 도감: 전체 1,025종 목록, 이름/번호 검색, 공식 지방별 그룹 선택, 타입 필터, 이름순/번호순 정렬, 공식 도감의 작품별 설명·타입·분류·성별·키·몸무게와 모든 특성의 설명. 공식 진화 단계와 분기, 메가진화·지역별 모습·거다이맥스 등 다른 모습을 이미지로 표시합니다. 관련 포켓몬을 누르면 사이트 안에서 상세 도감으로 이동합니다.

- 색칠놀이: 도감 레이어 하단의 팔레트 아이콘으로 현재 포켓몬(다른 모습 포함)의 도안을 엽니다. 도안만 보이는 레이어 아래에서 출력하기를 누르면 A4 한 장에 인쇄합니다. 레이어 바깥을 누르거나 Escape로 닫으면 보던 도감 카드로 돌아갑니다. 단순한 윤곽선으로 변환하며 별도 서버나 추가 이미지 저장은 필요 없습니다. 자동 윤곽선 변환이므로 일부 작은 무늬나 낮은 대비의 경계는 생략될 수 있습니다.

## 실행

정적 사이트이므로 `dist`를 제공하는 HTTP 서버로 실행할 수 있습니다.

```sh
python3 -m http.server 4173 --bind 127.0.0.1 --directory dist
```

로컬 실행에는 별도 설치나 빌드가 필요하지 않습니다. AWS용 검증·배포 절차는 아래 CI/CD 안내를 참고하세요.

## 데이터 출처

`dist/pokemon.json`은 각 포켓몬의 공식 도감 URL과 원본 이미지 URL을 기록합니다. `scripts/import-official.py`는 공식 상세 정보와 진화·모습으로 연결된 관련 항목을 재수집하는 스크립트입니다. 퀴즈와 목록은 도감번호별 대표 모습 1,025종을 제공하며, `dist/pokemon-details.json`에는 다른 모습 277개의 상세 정보를 담았습니다. `dist/pokedex-manifest.json`에 공식 목록 수, 기본 포켓몬 수와 다른 모습 수를 기록합니다. 수집은 공식 목록의 마지막 페이지까지 확인하며 모든 도감번호의 누락 여부를 검증합니다. 상세 화면의 외부 링크는 제공하지 않습니다. 수집일: 2026-10-01. 이미지는 사이트에 포함하여 게임 도중 외부 도감 이미지 서버에 의존하지 않습니다.

포켓몬은 Nintendo / Creatures Inc. / GAME FREAK inc.의 지식재산입니다. 본 사이트는 비공식 팬 게임입니다.

타임어택 시작 화면은 랜덤 포켓몬과 가운데 시작 버튼으로 구성합니다. 마스터 도전은 각 난이도의 실제 이미지 미리보기(어려움은 실루엣)를 제공합니다. 첫 문제를 불러오는 동안 스피너를 표시하고 이미지가 준비되면 게임을 시작하고, 타임어택은 그때부터 시간을 잽니다. 메인 화면은 퀴즈 중심으로 구성하며 상단 메뉴와 우측 배너 없이 하단 링크로 도감과 랭킹에 접근합니다. 타임어택의 타임바는 문제를 바꿔도 유지되며 남은 시간에 비례해 감소합니다.

도감 팝업은 메인 타입 색상의 카드이며 공식 패턴, 타입·성별 아이콘을 사용합니다. 반투명 닫기·팔레트 도구는 본문 끝과 레이어 하단 테두리 사이에 같은 간격으로 떠 있고, 마지막 내용을 가리지 않도록 본문 끝에 여백을 둡니다. 특성 설명은 항상 펼쳐져 있고 Pokémon LEGENDS Z-A를 포함한 공식 작품 태그를 표시합니다. 메인 이미지는 원본 크기(좁은 화면에서는 화면 너비에 맞춤)로 표시합니다. `scripts/import-ui-assets.py`와 `dist/ui-assets.json`에 UI 이미지 수집 방법과 공식 원본 출처를 기록합니다.

두 퀴즈 모드 모두 출제 순서에 맞춰 다음 세 문제의 이미지를 미리 불러오고 디코딩합니다. 준비된 이미지 요소를 그대로 표시해 문제 전환 시 로딩을 줄이며, 메모리에는 현재 문제와 다음 문제들만 유지합니다.

## 접근성

키보드 숫자 1–4로 객관식 선택, Enter로 주관식 제출, Escape로 도감 닫기. 정답 피드백은 라이브 영역으로 안내합니다. 타임어택 타이머는 실제 경과시간을 기준으로 하여 다른 탭으로 이동해도 계속 흐릅니다. 모바일 레이아웃과 동작 줄이기 설정을 지원합니다.

마스터 도전의 모바일 화면은 스크롤 없이 포켓몬을 고정하고, 키보드 상태와 관계없이 입력칸과 확인/다음문제 버튼을 이미지 위에 띄웁니다. 판정 효과 이미지는 떠 있는 입력칸 위에 배치해 가리지 않도록 합니다. 문제 수는 왼쪽, 점수는 오른쪽, 패스는 가운데에 표시합니다. 힌트는 이미지 왼쪽 위의 반투명 흰색 원형 버튼에 노란 아이콘으로 표시합니다. 힌트 글자는 해당 칸에 채워지고, 남은 빈칸만 입력합니다. 입력 요소를 문제 사이에 유지해 키보드와 입력 흐름을 보존하며, 안내 메시지는 입력칸 위에 띄워 표시하고 별도 하단 공간을 두지 않아 이미지 영역을 더 크게 사용합니다. 점수 줄과 작은 도움 버튼은 계속 표시합니다.

지원 브라우저에서는 WebMCP를 통해 퀴즈 시작/상태/답안 제출과 도감 검색을 사용할 수 있습니다. 지원하지 않는 브라우저에서도 게임은 정상 작동합니다.

## AWS 배포와 CI/CD: pokemon.pir.kr

podcast와 같은 CDK 기반 비공개 S3 + CloudFront OAC + ACM + 기존 Route 53 구조를 사용합니다. `himinseop/pokemon`의 PR과 main push에서 사이트와 인프라를 검증하고, AWS 최초 설정 후 main의 검증된 릴리스를 GitHub Actions OIDC로 자동 배포합니다. 장기 AWS 키는 GitHub에 저장하지 않습니다.

설정은 `infra/config.json`, 파이프라인은 `.github/workflows/aws.yml`에 있습니다. [최초 AWS 설정·GitHub 연결·운영 및 복구 절차](docs/aws-deployment.md)를 참고하세요. `npm run ci`는 로컬 검증과 빌드/CloudFormation 생성을 수행하며 AWS 리소스를 변경하지 않습니다. `AWS_DEPLOY_ENABLED=true`를 설정하기 전에는 검증만 실행하고 배포는 건너뜁니다.

```sh
npm ci
npm run ci
```

`npm run aws:deploy -- --profile podbbangcast`는 인프라를 생성합니다. `npm run aws:publish -- --profile podbbangcast`는 검증된 `dist-aws` 파일을 게시합니다. 기존 수동 S3 업로드용 ZIP은 `python3 scripts/package-aws.py`로 계속 만들 수 있습니다. 랭킹은 AWS DynamoDB에 저장하여 함께 공유합니다. 기존 개인 localStorage 기록은 삭제하거나 자동 공개하지 않습니다.

지방 그룹은 `scripts/import-regions.py`로 공식 도감의 11개 지방 필터(미확인 포함)를 마지막 페이지까지 수집하여 `dist/pokemon-regions.json`에 기록합니다. 다른 모습으로 지방에 속하는 경우 해당 종도 포함하므로 그룹이 겹칠 수 있습니다. 타임어택 랭킹은 3개 난이도로 분리하고, 기존 타임어택 기록은 보통 랭킹에서 유지합니다.

버튼 포커스에는 blur를 적용해 클릭·프로그램 포커스 시 외곽 포커스 표시가 남지 않습니다. 도감 원형 도구는 마우스를 올리거나 눌러도 반투명 배경을 유지합니다. 자동 배포는 정적 파일과 Lambda 코드만 바꾸며, 보존 정책의 DynamoDB 랭킹 테이블 및 기존 기록을 초기화하지 않습니다.
