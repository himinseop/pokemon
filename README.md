# 포켓몬 플레이

아이들을 위한 한국어 포켓몬 퀴즈. 공식 한국 포켓몬 도감의 관동지방 기본 모습 151마리를 사용합니다.

- 타임어택: 60초, 4지선다, 정답 100점. 연속 정답 보너스는 10점씩 늘어나며 최대 100점입니다.
- 마스터 도전: 한글 이름 입력, 10문제. 쉬움은 친숙한 43마리·30초, 보통은 151마리·20초, 어려움은 151마리 실루엣·15초입니다. 기본 100점에 남은 초당 2점을 더한 뒤 난이도 배수 1/2/3을 적용합니다.
- 기록: 별명과 결과를 브라우저에 저장하고 모드·난이도별 상위 20개를 보여줍니다. 같은 기기에서 경쟁할 수 있으며 온라인 공동 순위 기능은 포함하지 않습니다.
- 도감: 이름/번호 검색, 타입 필터, 이름순/번호순 정렬, 분류·특성·키·몸무게·짧은 공식 설명과 출처 링크.

## 실행

정적 사이트이므로 `dist`를 제공하는 HTTP 서버로 실행할 수 있습니다.

```sh
python3 -m http.server 4173 --bind 127.0.0.1 --directory dist
```

별도 설치나 빌드가 필요하지 않습니다. Sites의 비공개 사이트로 게시됩니다.

## 데이터 출처

`dist/pokemon.json`은 각 포켓몬의 공식 도감 URL과 원본 이미지 URL을 기록합니다. `scripts/import-official.py`는 공식 데이터를 재수집하는 스크립트입니다. 수집일: 2026-10-01. 이미지는 사이트에 포함하여 게임 도중 외부 도감 이미지 서버에 의존하지 않습니다.

포켓몬은 Nintendo / Creatures Inc. / GAME FREAK inc.의 지식재산입니다. 본 사이트는 비공식 팬 게임입니다.

## 접근성

키보드 숫자 1–4로 객관식 선택, Enter로 주관식 제출, Escape로 도감 닫기. 정답 피드백은 라이브 영역으로 안내합니다. 타이머는 실제 경과시간을 기준으로 하여 다른 탭으로 이동해도 계속 흐릅니다. 모바일 레이아웃과 동작 줄이기 설정을 지원합니다.

지원 브라우저에서는 WebMCP를 통해 퀴즈 시작/상태/답안 제출과 도감 검색을 사용할 수 있습니다. 지원하지 않는 브라우저에서도 게임은 정상 작동합니다.
