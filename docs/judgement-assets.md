# 퀴즈 판정 효과

2026-10-02에 승인한 귀여운 그래피티 시안을 기준으로 built-in image_gen 도구에서 각 문구를 별도로 투명 배경 편집했습니다.

파일은 `dist/assets/judgements/`의 `good.png`, `great.png`, `perfect.png`, `awesome.png`, `fail.png`입니다. 모두 RGBA PNG이며 배경의 실제 알파 투명도를 확인했습니다.

공통 제작 프롬프트: 승인한 다섯 줄 시안에서 지정한 문구 하나만 독립된 게임 스티커로 추출한다. 둥글고 통통한 그래피티 글자, 흰 외곽선, 검은 윤곽 및 입체감, 스프레이 질감, 부드러운 별과 물방울 장식을 유지한다. 나머지 문구와 남색 배경을 제거하고 실제 투명 알파 배경을 사용한다. 글자와 장식을 자르지 않고 가로로 중앙 정렬한다. 7~8세를 위한 친근한 리듬게임 효과로 만들며 추가 문구나 캐릭터를 넣지 않는다.

| 문구 | 색상 | 표시 조건 |
| --- | --- | --- |
| GOOD | 라임 초록 | 연속 1~2회 |
| GREAT | 청록·파랑 | 연속 3~4회 |
| PERFECT | 노랑·주황 | 연속 5~6회 |
| AWESOME | 분홍·보라 | 연속 7회 이상 |
| FAIL | 코랄 빨강, 구름 장식 | 오답·건너뛰기 |

판정은 정답 처리 후의 연속 횟수를 기준으로 매번 표시합니다. 주관식 오답은 현재 문제의 재도전 흐름을 유지하며 연속 횟수를 초기화합니다. 효과는 500ms 표시하고, 정답 후 550ms / 오답 후 1300ms의 기존 문제 전환 시간을 유지합니다. 동작 줄이기 설정에서는 움직임 없이 표시합니다.

로컬 확인: `npm start`로 실행한 뒤 `http://127.0.0.1:4173`에서 확인합니다. 검증은 `npm run check` 및 `npm test`입니다.
